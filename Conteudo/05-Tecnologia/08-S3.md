# Amazon S3 — Referência Rápida

> Ficha de referência para a prova DVA-C02

---

## Descrição

**O que é:** Serviço de armazenamento de objetos com durabilidade de 99,999999999% (11 noves). Suporta versionamento, lifecycle policies, replicação, notificações de eventos, criptografia e controle de acesso granular.

**Para que usamos:** Data lakes, hospedagem de sites estáticos, origem de eventos para Lambda via S3 Notifications, backup com lifecycle para Glacier, distribuição de assets via CloudFront, upload direto do cliente com Pre-Signed URLs.

**Exemplo de prova:** Uma aplicação web precisa permitir que usuários façam upload de arquivos de até 5 GB diretamente para o S3 sem passar pelo servidor da aplicação (para reduzir custo de transferência e carga). Como implementar de forma segura?
→ Gerar uma **S3 Pre-Signed URL** com método `PUT` no backend (usando SDK + credenciais da role IAM). O cliente usa a URL temporária para fazer upload diretamente ao S3. Para arquivos >100 MB, considerar **Multipart Upload** com Pre-Signed URLs por parte. A URL expira após o tempo configurado, garantindo segurança.

## Limites

| Item | Valor |
|---|---|
| Tamanho máximo de objeto | 5 TB |
| Upload direto (PutObject) | Até 5 GB |
| Multipart obrigatório | > 5 GB |
| Multipart recomendado | > 100 MB |
| Buckets por conta | 100 (padrão) |

## Classes de armazenamento

| Classe | Acesso | Mín. dias | AZs |
|---|---|---|---|
| Standard | Imediato | — | ≥3 |
| Standard-IA | Imediato | 30 dias | ≥3 |
| One Zone-IA | Imediato | 30 dias | 1 |
| Intelligent-Tiering | Imediato | — | ≥3 |
| Glacier Instant | Imediato | 90 dias | ≥3 |
| Glacier Flexible | 1-12h | 90 dias | ≥3 |
| Glacier Deep Archive | 12-48h | 180 dias | ≥3 |

## Criptografia

| Tipo | Gerenciamento chave |
|---|---|
| SSE-S3 | AWS (AES-256) |
| SSE-KMS | KMS (auditável) |
| SSE-C | Cliente fornece chave |
| CSE | Cliente criptografa antes de enviar |

---

## Event Notifications

- Triggers: ObjectCreated, ObjectRemoved, ObjectRestore, Replication.
- Destinos: Lambda (assíncrono), SQS, SNS, EventBridge.

---

## Presigned URL

- GET: download temporário sem credenciais.
- PUT: upload sem credenciais.
- Máximo: 7 dias (604.800 s).
- Usa credenciais de quem gerou a URL.

---

## Versionamento

- Após habilitar: não pode desabilitar (somente suspender).
- MFA Delete: protege versões e suspensão de versioning.
- Delete de objeto com versioning: cria delete marker.

---

## S3 Object Lambda

- Transforma dados no `GetObject` via Lambda.
- Casos de uso: remover PII, converter formato, redimensionar imagem.
